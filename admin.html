Налоги

Налоги включены

Выключено — везде, где показываются налоги (раздел «Налоги», колонка «Налог» в «Группах», фильтры «Платил» в «Посещаемости», налоги в «Моём кабинете», график в «Динамике»), пишется «выключен» или налогов просто нет. Данные об оплатах не удаляются: включишь обратно — всё вернётся как было.

Налог за неделю

Сумма налога с одного человека за неделю. Используется в окошке «Итого за неделю» на странице «Налоги» — просто множится на число заплативших и складывается с донатами, саму отметку «кто платил» это не меняет.

Шаблон отчёта по налогам

Готовый текст для кнопки «📋 Скопировать отчёт» на странице «Налоги» — набирается один раз, дальше просто копируется каждую неделю с уже подставленными числами. Плейсхолдеры: {total} — общая сумма сбора, {taxAmount} — сумма с человека, {regularCount} — заплатили обычным способом, {aheadCount} — заплатили наперёд, {debtCount} — закрыли долг, {payerCount} — всего заплативших, {list} — пронумерованный список ников.

Включённые разделы ДКП

Полностью выключает раздел для всего клана — исчезает из меню у абсолютно всех, независимо от роли (та же настройка, что в «Разделы и права» → «Какие разделы вообще есть», просто отдельно и под рукой здесь).

Раздел дропа

Показывать только тех, кто хоть раз ходил за отмеченный период

Выключено — виден весь состав из последней переписи, даже с 0 начальных баллов. Включено — те, у кого начальных баллов 0, из таблицы пропадают.

Минимальный % буста

Применяется только к тем, у кого в «Проверке буста» не отмечено вообще ничего (реальный % = 0) — вместо 0% используется этот минимум, в том числе в «ДКП Соло»/«ДКП Пати». Как только у человека отмечен хоть один пункт — минимум отменяется, используется его настоящий процент, даже если он ниже минимума. 0 — выключено.

Ушедшие из клана в «Раздаче»

Показывать в списке тех, кто уже вышел из клана

Этот переключатель влияет только на то, видна ли сама строка ушедшего (в ней всегда 0). Куда идёт его доля — решает настройка «Доля ушедших из клана» ниже.

Где ещё был человек в «Раздаче»

Показывать под ником «ещё у: …»

Тусклая строка под ником в списке лидера: у каких других лидеров этот человек был за период (например «ещё у: Пятка ×2»). Выключено — строка не показывается, суммы не меняются.

Доля ушедших из клана

Ушедшим из клана (нет в последней переписи) в «Раздаче» всегда 0. Эта настройка решает, куда идёт их доля: поровну остальным в той же пати, поровну всем оставшимся в клане, в отдельное окошко «Доли ушедших» (ничего не делится, клан-лидер решает сам) или никуда.

Коэффициент пати-лидерам

Свой множитель для каждого текущего пати-лидера (Группы → лидер) — коэффициенты не складываются: у лидера этот множитель ЗАМЕНЯЕТ собой коэффициент профессии, а не добавляется поверх него. На саму пати не влияет; в «ДКП Соло» — только если включена галочка ниже. Список — по тем, кто прямо сейчас отмечен лидером хоть одной пати; нет строки — считается как 1.

Применять коэффициент лидера и в «ДКП Соло»

Выключено — в «ДКП Соло» лидер считается как все, по коэффициенту своей профессии. Включено — в «ДКП Соло» у лидера пати вместо коэффициента профессии берётся его коэффициент лидера из списка ниже.

Ни в одной пати пока не назначен лидер (Группы → лидер).

Коэффициент профессии для «ДКП Соло»

У каждой профессии свой множитель: финальные баллы участника = начальные баллы × % буста × этот коэффициент. Нет строки для класса — считается как 1.

Коэффициент пати для «ДКП Пати»

У каждой пати свой множитель: финальные баллы пати = начальные баллы × % буста × этот коэффициент. Нет строки для пати — считается как 1.

Какие разделы видит каждая роль

Снимите галочку — раздел исчезнет из навигации у всех с этой ролью. Админ-панель всегда видна только главному админу.

Цветовая схема

Общий тёмный фон везде одинаковый, меняется только акцентный цвет (заголовки, ссылки, кнопки). Применяется сразу всем в клане.

Свой акцентный цвет

Необязательно — точечно подменяет цвет акцента поверх выбранной схемы выше, если хочется свой конкретный оттенок.

Название и лого

Подменяет заголовок «Кабинет клана» в шапке сайта и логине. Оставьте пустым, чтобы использовать значение по умолчанию.

Названия ролей

Своё название роли только для вашего клана — права и ранг не меняются, меняется только то, как роль называется на экране. Пусто — используется название по умолчанию (слева).

Резервная копия данных

Одним нажатием сохраняет на твой компьютер все данные клана одним файлом: перепись, явку, статистику, налоги, группы, буст, ДКП, привязки ников, настройки. Если что-то случайно удалят или сломают, данные можно будет вернуть.

Проверить файл копии

Выбери сохранённый файл — покажем, когда он сделан и сколько в нём строк по каждой таблице. Так можно убедиться, что копия целая и читается.

Файл не выбран

Восстановить из копии

Выбери файл копии — сайт сравнит его с тем, что в базе сейчас, и покажет, чего не хватает. Ничего не удаляется: возвращаются только пропавшие строки (а при желании — и изменённые приводятся к виду из копии). Логины, пароли и профили людей не восстанавливаются.

Файл не выбран

Что в копии, а что нет

  • Входит: данные только вашего клана и профили его людей (ник, роль, пати) — без паролей. Данные других кланов в копию не попадают.
  • Не входит: логины и пароли (хранятся в закрытой части Supabase — после полного сбоя пароли придётся выдать заново), схема базы и правила доступа (они лежат в папке supabase/ в репозитории сайта).
  • Храните файл не только на этом компьютере: облако, флешка или другой диск. Файл содержит ники и данные клана — не выкладывайте его публично.
